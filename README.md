# Dragon
Collaborative project developed with two colleagues. I gained experience with C++ coding principles and data structures in the context of a complex project, while also working with the OpenGL graphics library.
Specifically, I worked on the design and implementation of:
- Main game loop system
- Graphical classes (sprite_renderer, shader, texture, post_processor)
- Post processing shaders
- Gameplay logic, data structures for increasing difficulty and levels (game_level, game_object, bullet)
